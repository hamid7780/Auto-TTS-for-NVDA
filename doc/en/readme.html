Auto TTS for NVDA

Auto TTS automatically detects text language and switches between the voices selected for each language. It supports multilingual content, including Urdu, Arabic and English.

Setup

  1. Open NVDA menu, Preferences, Settings, Auto TTS.
  2. Add a profile for each language and select its synthesizer and voice.
  3. Choose your default language. Enable custom rate, pitch and volume if needed.
  4. Use Test Speech to check the voices, then save settings.
  5. Press NVDA+Ctrl+S and select Auto TTS for NVDA as the synthesizer.

Additional synthesizers and voices must be installed separately.

Language settings

Word-by-Word mode is suitable for mixed-language sentences. Sentence and line modes can reduce frequent voice changes. Choose Detect from text for automatic detection, or Trust document language tags to follow the document's settings.

Offline detection uses enabled language profiles. Short or ambiguous text may keep the current language. Math and numbers can use the current language or another language selected in settings.

Keyboard shortcuts

Default Auto TTS shortcuts
ShortcutAction
NVDA+Alt+AOpen Auto TTS settings.
NVDA+Shift+LTurn automatic language switching on or off.
NVDA+Alt+LLock speech to a language or unlock it.
NVDA+Ctrl+TAnnounce Auto TTS status.

Change shortcuts under Preferences, Input gestures, Auto TTS. Language lock ends when NVDA restarts. NVDA's synthesizer settings ring can also change the selected profile's speech settings.

Applications and backups

Excluded applications use the default language without automatic switching. Some editors and terminals are excluded by default. Edit the exclusions list to enable switching in those applications.

Use Export Settings to save language profiles and Import Settings to restore them. Language detection runs locally. Online synthesizers may require an internet connection.

Support

If the wrong voice speaks, check that Auto TTS is selected, the language profile is enabled, language lock is off, and the application is not excluded.

Report a problem with your NVDA version, voices and steps to reproduce it.
