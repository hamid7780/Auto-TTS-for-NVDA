Auto TTS for NVDA

Version 1.0.0. Author: Raja Hamid. Minimum NVDA: 2023.3. Last tested NVDA version declared in the manifest: 2026.1.1.

Auto TTS automatically switches between configured voices and synthesizers while NVDA reads multilingual text. Each language can have its own rate, pitch and volume. Mixed-language text stays in its original order.

Getting started

  1. Install your additional synthesizers and voices separately.
  2. Open NVDA menu, Preferences, Settings, Auto TTS, or press NVDA+Alt+A.
  3. Add an enabled profile for each language, then choose its synthesizer and voice.
  4. Enable custom prosody for profile-specific rate, pitch and volume. Otherwise, the profile uses the underlying synthesizer's settings.
  5. Set your usual language as the default, test speech, and save settings.
  6. Press NVDA+Ctrl+S, select Auto TTS for NVDA as the synthesizer, and confirm.

A fresh installation initially follows NVDA's language. eSpeak NG is available as a fallback. You do not need to install Python, fastText or a language model.

Detection settings

Use Word-by-Word for several writing scripts in one sentence. Sentence and line modes reduce switching. Use Detect from text for unreliable language tags, or Trust document language tags for correctly tagged books and web content.

Urdu/Arabic rules inspect characters and Quranic marks. Offline fastText detection helps distinguish configured languages sharing a writing script. It selects enabled profiles only and may retain the current language for short or ambiguous text. If the native detector cannot load, Unicode and document-tag routing remain available.

Math follows the current language by default; an enabled profile can be selected for math instead. Number-language behavior is configurable. Excluded applications use the default profile without automatic switching. Common editors and terminals are initially excluded; edit the exclusions list as needed.

Keyboard shortcuts

Default Auto TTS and NVDA settings-ring shortcuts
ShortcutAction
NVDA+Alt+AOpen Auto TTS settings.
NVDA+Shift+LToggle automatic language switching.
NVDA+Alt+LChoose a profile to lock the language, or unlock.
NVDA+Ctrl+TAnnounce status and language lock.
NVDA+Ctrl+Left/RightSelect a synthesizer settings-ring item.
NVDA+Ctrl+Up/DownChange the selected settings-ring value.

Reassign Auto TTS shortcuts in Preferences, Input gestures, Auto TTS. Language lock lasts only for the current session. The ring lists configured profiles; custom prosody changes apply to the selected profile, while other prosody changes apply to its underlying synthesizer.

Settings and backups

Use Export Settings to save a separate .autotts or JSON backup, and Import Settings to restore one. Settings live in addons/autoTTS.json inside NVDA's user configuration directory, outside the add-on package. The previous complete settings are kept in autoTTS.json.bak. Profiles can be recovered from missing, corrupt or unexpectedly empty primary settings.

If you used a higher-numbered development package, export settings before replacing it with 1.0.0. NVDA may display a downgrade prompt.

Privacy and troubleshooting

Language identification runs locally without uploading text or downloading a model. A third-party synthesizer may use an online service and follows its own network behavior and privacy policy.

If the wrong voice speaks, check that Auto TTS is active, the profile is enabled, language lock is off, the application is not excluded, and the chosen voice supports the language. Sequential mixed-synth speech depends on reliable completion notifications from the underlying drivers.

When reporting a problem, include NVDA and Auto TTS versions, synthesizers, voices, relevant settings, sample text and reproduction steps. Remove private content from samples and logs before posting publicly.
