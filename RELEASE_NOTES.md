## What's new in 1.0.2

- Cancelling speech now stops only the voices that were speaking, which should reduce the small delay some people felt after pressing a key.
- Slow calls are written to the NVDA debug log, so late speech can be investigated.
- The user guide is rewritten and now lists the excluded applications and the known limitations.

## About Auto TTS for NVDA

Auto TTS detects the language of the text NVDA reads and switches to the voice you chose for that language. It works offline and is built for mixed Urdu, Arabic and English, and it supports many other languages.

Download **autoTTS-1.0.2.nvda-addon**, open the file and restart NVDA. Then open **Preferences > Settings > Auto TTS for NVDA** (or press **NVDA+Alt+A**), add a profile for each language, and press **NVDA+Ctrl+S** to select **Auto TTS for NVDA** as your synthesizer.

Minimum NVDA version: **2023.3**. Last tested NVDA version: **2026.2**.
